# Maharashtra Weather Analysis 🌦️

## About
Analyzed weather data across 36 cities in Maharashtra from 2020 to 2025 
containing temperature, rainfall and atmospheric pressure records.

## What I did
- Cleaned raw weather data (missing values, dropped irrelevant columns)
- Extracted year and month from date column for time-based analysis
- Created 8 visualizations using Matplotlib
- Extracted insights on temperature patterns, rainfall and pressure

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Lab

## Key Finding
Coastal cities maintain consistently higher average temperatures while 
inland cities experience extreme heat peaks. Atmospheric pressure follows 
a perfect V-shape pattern directly correlating with monsoon rainfall.
